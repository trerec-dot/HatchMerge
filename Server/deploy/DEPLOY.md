# Сервер игроков на VPS

После установки игра сможет находить игроков по ID через интернет, а не только в одной Wi-Fi сети.
Сервер работает круглосуточно, сам перезапускается при сбоях и после перезагрузки VPS,
работает по HTTPS и каждый день делает резервную копию базы.

## 1. Арендуйте VPS

Подойдёт самый простой тариф у любого хостинга:

- система **Ubuntu 24.04** (или 22.04, Debian 12);
- 1 ядро, 1 ГБ памяти, 10 ГБ диска — с запасом;
- публичный **IPv4-адрес**;
- регион поближе к игрокам.

После создания хостинг покажет **IP-адрес** и **пароль root** (или предложит добавить SSH-ключ).
Если в панели хостинга есть свой брандмауэр, откройте в нём порты **22, 80 и 443**.

## 2. Домен (по желанию, но лучше с ним)

- **Со своим доменом:** у регистратора домена создайте A-запись, например `game.вашдомен.ru → IP VPS`.
  Запись начинает работать через 5–30 минут.
- **Без домена:** ничего делать не нужно — установщик возьмёт адрес вида `203-0-113-5.sslip.io`,
  который ведёт на ваш VPS. Это бесплатный сервис; для постоянной игры надёжнее свой домен.

## 3. Установите сервер

В папке проекта запустите `Server\deploy\deploy_to_vps.bat`:

1. введите IP-адрес VPS;
2. введите домен (или просто нажмите Enter);
3. при первом подключении ответьте `yes` и введите пароль root (до трёх раз).

Установка занимает 1–3 минуты. В конце появится адрес, например:

```
   https://game.вашдомен.ru
```

## 4. Подключите игру

1. Откройте `Assets/Resources/server_url.txt` и впишите адрес отдельной строкой, без `#`:
   ```
   https://game.вашдомен.ru
   ```
2. Пересоберите игру. При запуске она подключится к VPS, а в настройках будет видно
   «Сервер: game.вашдомен.ru».

Старые ID с домашнего сервера на VPS не переносятся — игра сама получит новый ID при первом подключении.
Чтобы перенести базу целиком, скопируйте её до первого запуска игры с VPS:

```
scp Server\hatchmerge.db root@IP:/var/lib/hatchmerge/hatchmerge.db
ssh root@IP "chown hatchmerge:hatchmerge /var/lib/hatchmerge/hatchmerge.db && systemctl restart hatchmerge"
```

## 5. Проверка

Откройте адрес в браузере: страница «Сервер работает» и число игроков / игроков в сети.
Список игроков в интернете намеренно не показывается.

## Страница администратора

`https://ваш-адрес/admin` — все игроки с почтой, статусом и прогрессом, поиск по ID, почте и имени,
карточка игрока с сохранением (энергия, настройки, яйца на поле) и открытыми животными.
В карточке игрока можно:
- **начислить или списать** монеты, кристаллы и энергию (минус — списать). Игра применит изменение
  при следующей связи с сервером (до 20 секунд, офлайн-игроку — когда вернётся); ещё не полученное
  изменение можно отменить;
- **заблокировать** игрока с причиной — игра покажет экран блокировки, вход в аккаунт и поиск
  игрока перестанут работать; **разблокировать** — игра вернётся в меню в течение 20 секунд.
  Блокируется ID игрока: если ребёнок переустановит игру без аккаунта, он получит новый ID;
- все действия записываются в журнал администратора (время, действие, IP).

Страница закрыта паролем: установщик создаёт его сам и показывает в конце установки.
Посмотреть или сменить пароль: `cat /etc/hatchmerge.env` (сменить — `nano /etc/hatchmerge.env`,
затем `systemctl restart hatchmerge`). На главной странице без пароля видны только общие цифры.

## Обслуживание

| Задача | Как |
|---|---|
| Обновить код сервера | снова запустить `deploy_to_vps.bat` (данные игроков сохранятся, база обновится сама) |
| Журнал сервера | `ssh root@IP` → `journalctl -u hatchmerge -f` |
| Перезапустить | `systemctl restart hatchmerge` |
| Резервные копии | `/var/backups/hatchmerge`, каждый день в 03:30, хранятся 14 дней |
| Восстановить копию | `systemctl stop hatchmerge`, `gunzip -c /var/backups/hatchmerge/hatchmerge-ДАТА.db.gz > /var/lib/hatchmerge/hatchmerge.db`, `chown hatchmerge:hatchmerge /var/lib/hatchmerge/hatchmerge.db`, `systemctl start hatchmerge` |
| Обновления системы | раз в месяц: `apt update && apt upgrade -y` |

## Безопасность

- Лучше войти по SSH-ключу и отключить вход по паролю (`PasswordAuthentication no` в `/etc/ssh/sshd_config`).
- Наружу открыты только SSH, 80 и 443; сам сервер игры слушает только внутри VPS, снаружи до него
  доступ есть лишь через Caddy по HTTPS.
- Сервер ограничивает число регистраций и поисков с одного адреса, а статус игрока может менять
  только его собственная игра (по секретному ключу).
